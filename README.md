## How to run

1. Download `cosmoquest_space_explorer.html`.
2. Open it in Chrome, Edge or Firefox.
3. No Node.js, database, server or API key is required.
4. Internet is recommended because images are loaded from Unsplash.

## GitHub Pages

1. Create a GitHub repository.
2. Rename `cosmoquest_space_explorer.html` to `index.html`.
3. Upload `index.html` and this README.
4. Go to **Settings → Pages**.
5. Select your main branch as the deployment source.

## Technologies

HTML5, CSS3, Vanilla JavaScript, CSS Grid, Flexbox, Local Storage, DOM manipulation, form validation and responsive design.

## Important note

This is a frontend educational project. Mission and astronomy-event data are demo data rather than a live NASA/ESA feed. No backend or API is connected.

The site uses remote Unsplash images so the project can remain one complete HTML file. For a fully offline submission, download the images into an `images/` folder and replace the image URLs.
